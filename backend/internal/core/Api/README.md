# Api

Infraestructura REST JSON bajo /api/v1 y /api/internal/v1: autenticación, límites, validación común, errores y correlación. Los módulos aportan sus controladores y rutas. OpenAPI 3.1 es la propuesta documental.

Área del [Core](../README.md), no un módulo de negocio. Estructura documental pendiente de implementación.
