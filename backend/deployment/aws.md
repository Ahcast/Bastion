# AWS para Bastion

Lightsail ejecuta backend Go, API, MCP, crawler Python y workers. S3 almacena archivos y respaldos. El frontend, MySQL y correo permanecen en Bluehost. No se ejecutan OCR ni modelos locales en Lightsail.

No se necesita servidor MySQL en AWS para esta arquitectura. Ver [Core](../../docs/architecture/core.md).
