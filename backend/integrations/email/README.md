# 44. Email

El correo actual se encuentra en Bluehost.

El sistema debe poder:

- redactar RFQ;
- enviar RFQ;
- asociar correo con RFQ;
- leer respuesta;
- extraer precio;
- lead time;
- stock;
- MOQ;
- freight;
- términos;
- validez;
- datasheets.

Cada RFQ debe tener ID único:

```text
RFQ-2026-00582
```

para correlacionar replies.
