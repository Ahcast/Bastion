# Módulos aprobados

Los 12 módulos de la sección 8.2 del [documento maestro](../../../../docs/Proyecto_Bastion_Documento_Maestro.md), con nombres en español conforme al [requisito obligatorio](../../../../docs/idioma.md).

| Módulo | Responsabilidad |
| --- | --- |
| Nucleo | Núcleo transversal y configuración |
| Clientes | Clientes |
| Proveedores | Proveedores |
| Procesos | Procesos |
| Cotizaciones | Cotizaciones |
| OrdenesCompra | Órdenes de compra de clientes |
| Facturas | Facturas |
| Gastos | Gastos |
| Reportes | Reportes |
| Colaboracion | Colaboración |
| FlujosTrabajo | Flujos de trabajo y autorizaciones |
| IA | Integración y estado de agentes de IA |

Inicio y Configuración son entradas del menú. No se agregan módulos distintos de los aprobados.
La organización interna de cada módulo se concretará al implementar; todos los nombres funcionales propios se redactarán en español.
