# 11. Módulo Inicio

Dashboard operativo.

Debe mostrar:

- procesos nuevos;
- procesos actualizados;
- procesos prioritarios;
- procesos asignados;
- cotizaciones pendientes;
- cotizaciones por vencer;
- órdenes activas;
- facturas pendientes;
- gastos;
- RFQ pendientes;
- proveedores sin respuesta;
- aprobaciones;
- tareas;
- actividad AI;
- errores del crawler;
- backups;
- alertas.

Feed de actividad:

```text
17:31 Grok encontró precio para item X
17:22 ENEE modificó proceso Y
17:10 proveedor respondió RFQ-581
16:58 cotización Q-1432 aprobada
16:40 OC cliente recibida
```
