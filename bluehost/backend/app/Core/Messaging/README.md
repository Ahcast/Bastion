# Messaging

Transporte de correo y notificaciones compartido. SMTP permanece en Bluehost. Settings administra su configuración; cada módulo controla finalidad, destinatario y autorización. Envíos en cola, con estado y conciliación de resultados inciertos.

Área del [Core](../README.md), no un módulo de negocio. Estructura documental pendiente de implementación.
