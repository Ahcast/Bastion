# Contrato de Cotizaciones

## Unidad actual: borradores y cálculo

Quotes posee quotes/quote_items/quote_versions/document_counters (migración 0006). Core no importa negocio. Composición inyecta servicios públicos transaccionales de Clientes y Procesos. Borradores manuales o desde proceso, editor, consulta paginada, cálculo canónico, clonación, historial y papelera/restauración constituyen esta unidad. PDF/S3, correo inmediato/programado, aprobación Workflow, bulk y conversiones a OC/Facturas conservan el alcance del módulo y siguen pendientes; esta unidad no acredita la aceptación completa de Cotizaciones. No avanzar al siguiente módulo.

## DTO y rutas

IDs/versiones son cadenas JSON. Input reemplaza todos los campos editables: customer {id,name,rtn,contact,phone,email,address}, reference, date (DATE ISO), validity_days (1..365), currency (HNL/USD), terms, private_notes, author_contact, exoneration_reference, general_discount_type (amount/percent), general_discount y items[] {description,unit,quantity,unit_price,unit_cost,discount_type,discount,tax}. Máximo 200 ítems; creación version="0", edición versión confirmada. Items vacíos solo borrador. La vinculación a cliente obtiene snapshot autorizado/activo; conservar mismo ID al editar mantiene el snapshot original. Cliente manual con id="" permite datos libres validados. Origen técnico no es editable; reference visible sí. Flete se captura como línea explícita con impuesto propio; no se inventa tratamiento fiscal.

GET/POST /api/v1/quotes; GET/PATCH /quotes/{id}; POST /quotes/calculate; POST /quotes/{id}/clone; GET /quotes/{id}/versions; DELETE /quotes/{id}; POST /quotes/{id}/restore. GET list acepta search literal (número/referencia/cliente/descripciones), deleted=true/false y page/per_page máximo 100. GET versions paginado. POST /api/v1/processes/{id}/create-quote con {date,version:"0"} usa fecha comercial explícita, copia solo entidad/expediente y deja ítems vacíos. GET /processes/{id}/quotes devuelve cotizaciones visibles (incluida papelera si solicitado), sin filtrar permisos por navegación solamente.

Salida Quote contiene id, number, status=draft, source_process_id, customer snapshot, campos editables, version, created_by/team_id, deleted_at, items con resultado por línea y calculation; List solo summaries. Migración mantiene cabecera e ítems como fuente maestra relacional y versiones JSON append-only de agregado/calculador (calculator_version=1); JSON no sustituye tablas actuales. Resultados de escrituras {id,version}. Idempotency-Key obligatorio, normalizado antes de hash; replay reautoriza y nunca refresca un snapshot ni consume otro consecutivo. Clonar genera nuevo número, conserva origen y snapshots, devuelve borrador; no copia adjuntos ni aprobaciones.

## Cálculo exacto v1

shopspring/decimal v1.4.0, solo constructores desde cadenas; ninguna aritmética financiera float64 ni dependencia del estado global de división. Cadenas sin exponentes/signos, hasta 18 dígitos totales y escalas quantity=4 (>0), unit_price/unit_cost=6 (>=0), descuentos de unidad=6, porcentaje=4 (0..100), descuento general absoluto=2. Valores negativos, descuentos mayores al precio/base, sobreflujo DECIMAL(18,2) y exoneración sin referencia son 422.

Descuento amount por unidad; percent = precio*porcentaje/100 exacto. Bruto de línea = round(quantity*price,2), neto antes de general = round(quantity*(price-unit_discount),2), descuento de línea = bruto-neto. Half-up a 2 decimales. Descuento general amount o round(suma netos*porcentaje/100,2). Distribución proporcional en centavos: cociente entero exacto, restos mayores primero, desempate por posición; suma asignada idéntica al descuento solicitado y ninguna base negativa. Base final por línea = neto-asignación. Tax enum isv15/isv18/exempt/exonerated, bases separadas. ISV por grupo = round(base*0.15/0.18,2), total = suma bases+ambos impuestos. Costos = suma round(quantity*unit_cost,2); margen antes de impuestos = suma bases-costos. Costos/margen/notas son internos, no futura salida pública. Desglose persistido se devuelve sin recalcularlo con otra versión. Moneda no implica conversión; FX y cálculos entre monedas conservan requisitos futuros y no se mezclan importes.

## Seguridad, estados y aceptación

cotizaciones.view/create/update/delete; scopes all/self/team, live RBAC/MFA; edición/clone requieren acceso de vista y acción. Borrador único estado activo de esta unidad: aprobación/emisión no se simulan con PATCH libre. Soft-delete/restauración requieren delete y reautenticación, versión e intención; sin hard-delete. Propietario derivado del actor; equipo inicialmente null (self/all), team para futuras asignaciones autorizadas, consulta respeta team. No escritura de máquinas. MCP get_quote/search_quotes solo lectura y mismo servicio, auditoría mínima. Flag BASTION_QUOTES_ENABLED=false retira rutas/tools sin borrar datos. Dependencias Core obligatoria; Clientes/Procesos opcionales: vincular/conversión falla cerrado si deshabilitados, manual sigue operativa.

Crear desde proceso exige procesos.view y cotizaciones.create, comprobados dentro de TX antes de replay. Resolver exacto aplica clientes.view; falta de grant no bloquea snapshot manual ni revela existencia. Entidad hasta 1000 caracteres; no autocrear maestro, no copiar descripción/documentos/notas/fecha/items. Varias intenciones crean varias cotizaciones. Numeración lock transaccional document_counters, UNIQUE number; fallo de auditoría revierte agregado/version/contador/eventos/intención. Eventos quote.created/updated/cloned/deleted/restored y process.quote_created transaccionales, sin jobs AI implícitos.

Aceptación: descuentos absolutos por unidad, porcentajes, cuatro impuestos, residuo exacto, límites/redondeos; MySQL5.7 migración/repetición, contador concurrente, intención concurrente, rollback, versión/IDOR/scopes/revocación, snapshots y conversión múltiple, UI conserva edición/clave ante fallos y no envía campos protegidos; navegador real. PDF/correo/aprobación/bulk/conversiones deben completar sus pruebas antes de cerrar TODO el módulo.
