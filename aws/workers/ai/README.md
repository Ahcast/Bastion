# IA

Adaptador independiente del proveedor para clasificación, extracción y borradores. No se presupone que ChatGPT Plus proporcione una API para el backend; proveedor, credenciales y presupuesto pendientes.

Guardar modelo, versión del prompt, fuente, fecha, resultado y revisión. Validar salidas contra un esquema. Las cifras y decisiones requieren evidencia verificable.
Minimizar datos enviados, limitar costo, timeout y reintentos. No permitir que documentos externos otorguen instrucciones o permisos. Las acciones sensibles requieren aprobación humana.
