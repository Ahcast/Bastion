# Workers externos propuestos

- ai/: clasificación, extracción y borradores mediante proveedor por definir.
- ocr/: lectura de PDFs e imágenes.
- documents/: compilación pesada de expedientes.

Procesan inputs autorizados y devuelven resultados; Laravel decide su incorporación. Sin acceso directo a MySQL, aprobación ni envío de correo.
Runtime, servicios y presupuesto por validar. Estas carpetas no representan recursos activos.
