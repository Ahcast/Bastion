# Módulos frontend

Pantallas de clientes, proveedores, procesos, cotizaciones, órdenes de compra, facturas, gastos, reportes y colaboración. Cada módulo expone rutas para carga diferida y consume Core y shared. No implementa otra autenticación ni importa servicios privados de otros módulos.

Inicio y Configuración están en [Core](../core/README.md). Identificadores técnicos en inglés; interfaz completa en español.

Los lineamientos funcionales y de arquitectura v2 se mantienen junto al módulo backend propietario para evitar duplicar reglas entre frontend y backend. Índice: [docs/modules/README.md](../../../../docs/modules/README.md).

Inicio, por no ser un dominio transaccional independiente, mantiene sus lineamientos en [core/pages/dashboard/LINEAMIENTOS.md](../core/pages/dashboard/LINEAMIENTOS.md).
