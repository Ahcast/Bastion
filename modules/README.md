# Módulos

Cada carpeta describe responsabilidad, relaciones y criterios de aceptación. La implementación futura debe mantener las reglas de negocio en backend.

| Módulo | Función |
| --- | --- |
| authentication | Sesiones y MFA |
| users-permissions | Usuarios, roles y políticas |
| processes | Procesos publicados e historial |
| tenders | Licitaciones y expediente |
| suppliers | Proveedores y trazabilidad |
| quotations | Costos y oferta económica |
| documents | Plantillas, generación e índice |
| approvals | Revisión y autorización |
| audit | Registro de acciones |
