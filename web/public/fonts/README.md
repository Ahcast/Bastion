# IBM Plex

Fuentes locales para conservar la dirección visual del frontend sin solicitudes a Google Fonts o CDN.

- IBM Plex Sans: latino, normal, pesos 400, 500 y 600.
- IBM Plex Mono: latino, normal, pesos 400 y 500.
- Fuente de los archivos: paquetes `@fontsource/ibm-plex-sans` y `@fontsource/ibm-plex-mono`, versión 5.3.0, publicados en el registro npm.
- Licencia: SIL Open Font License 1.1; se incluyen las licencias originales de ambos paquetes.

Los archivos WOFF2 están sin modificar. `plex.css` declara las caras con `font-display: swap`; las fuentes del sistema siguen disponibles como alternativa.
